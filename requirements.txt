# to its own CUDA driver, and pinning an exact torch version there
# forces a slow reinstall (and can land a build that doesn't match the
# runtime's CUDA). Floors keep local installs reproducible-enough while
# letting Colab use what it already has.
#
# NOTE: torch is intentionally NOT pinned to a +cuXXX build here. On a
# GPU runtime, install the CUDA build from PyTorch's own index; a plain
# `pip install torch` on Linux resolves a very large CUDA dependency
# chain that is unnecessary on CPU-only machines.
